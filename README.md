El proyecto del libro interactivo está enfocado en reforzar el aprendizaje del idioma ingles hacia niños de primaria de entre 6 a 12 años.
Este libro - proyecto es llamado "The Little Bookworm" en el cual el capitulo 1 consiste en el tema de los "Colores" , en este proyecto se muestra un menú en el cual se pueden seleccionar
3 temas, los cuales son 1-Colores 2-Familia y 3-Comida, al seleccionar el tema 1, es decir, Colores, se abrirá una ventana mostrando los 3 colores primarios, Rojo, azul y amarillo
y al presionar el botón "Siguiente", este será dirigido a otra pantalla que mostrará 3 colores secundarios y los colores primarios que se deben mezclar para lograr dicho color secundario
y al presionar nuevamente "siguiente", se abrirá la ventana en donde se debe realizar una actividad para ejecutar lo aprendido, la actividad muestra 3 colores secundarios
y cada uno contiene 2 opciones de mezclas de colores, por ejemplo opción 1 (Amarillo + Azul) opción 2 (Rojo + Amarillo) y se debe seleccionar la opción correcta que haga dicho color secundario. 
Al dar "siguiente" se irá a una ventana de "Resultados" en los cuales se mostrará cuantas respuestas correctas se obtuvo. Cada Vista o pantalla contiene además un botón de "Regresar" para visualizar la pantalla anterior
y también un botón de "Volver al Menú" que al presionarlo, volverá a la pantalla de menú para seleccionar alguno de los 3 temas.
